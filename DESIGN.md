# Machina interface

The desktop is agent-centric: wide central conversation and live work, left
sessions/navigation, and an editable companion pane that opens on demand.
The user approved three complete graphical presets: Volt, Afterimage and Chrome.
Their Nous/Hermes references emphasize engraved imagery, halftone texture,
electric ink blue, oversized serif and condensed technical display typography.
Custom backgrounds, adjustable glass/opacity/accent, self-hosted fonts and
state-driven ASCII motion are explicit user requirements. These supersede the
earlier restrained desktop direction. Keep motion isolated from transcript and
editor rendering, and allow it to be disabled. Retain buffers and drafts across
every appearance/layout change.

For the existing terminal client, preserve the code editor/explorer and adjacent harness.
Use existing semantic palettes, terminal fonts, spacing tokens, focus geometry,
and theme selectors. Tinted neutral surfaces carry most of the UI; accent marks
current selection and live activity. Keep tool history compact and disclose
details on demand. A small activity row above the harness composer summarizes
queued steering, running shell commands, and subagents. It expands into a clean
keyboard-driven activity view. Empty activity occupies no rows. Distinguish
pending, delivered, running, exited, stopped, and failed states in text.

Physical context: the user works for long coding sessions in their own terminal,
under varying lighting, so retain their selected dark or light theme.

All dynamic lists and output tails are bounded. Growable viewport children use
zero layout basis; retained transcript blocks cache multiple layout widths.
