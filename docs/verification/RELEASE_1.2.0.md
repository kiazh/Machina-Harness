# Machina 1.2.0

Models.dev-driven model picker.

## Changed

- Built-in provider listings now use the bundled `models.dev` snapshot generated by `tools/sync_models_dev.py`; metadata includes display name, context window, reasoning efforts, and description.
- The `/models` picker groups by readable provider names and shows compact rows such as the model name, context window, effort support, and description without repeating the provider on every row.
- Removed legacy duplicate curated rows; the fallback list is now one current row per family.
- Grok subscriptions keep a separate provider section with Grok 4.7, 4.7 Build Fast, 4.6, 4.5, 4.3, and Grok Build 0.1 where available.
- The xAI API-key provider remains `xai`; the OAuth subscription provider remains `grok`.

## Grok login

```bash
machina auth grok login
machina auth grok status
machina chat "hello" --provider grok --model grok-4.7
```

xAI may restrict OAuth inference by subscription tier. If inference returns 403
after a successful login, use `XAI_API_KEY` with the `xai` provider.

## Notes

Self-hosted open-source release, no hosted service or SLA. Model availability
still depends on the selected provider and account.
