# Third-party notices

## NotchAgents — island UI

The visual island layer in `Sources/MachinaNotch/NotchView.swift`,
`Sources/MachinaNotch/DotMatrix.swift`, and the adapter shapes in
`Sources/MachinaNotch/MakiAdapter.swift` is derived from **NotchAgents** by
Saksham Saini. The port keeps the notch silhouette, compact/expanded island
layouts, working aura, mesh background, dot-matrix readouts, alert layout, and
control styles, adapted for Maki as a single resident agent.

The port intentionally does **not** include NotchAgents' agent scanner,
hook server, usage ledger, OpenCode reader, or agent-store backend. Maki's
gateway client, model, voice input, screen capture, and chat remain our own.

Source: https://github.com/sakshamsaini12/NotchAgents
