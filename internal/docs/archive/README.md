current documentation. User-facing guides live in
[`../../../docs/`](../../../docs/); repository-wide files live at the
repository root (`README.md`, `OPERATIONS.md`, `SECURITY.md`,
`CHANGELOG.md`). The implementation ledger is
[`../../FEATURE_LEDGER.md`](../../FEATURE_LEDGER.md).

  persona/RSI, shell/context limits, handoff notes).
